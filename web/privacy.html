Privacy Policy

Last updated: November 26, 2026

Short version: the twnty app has no accounts and sends nothing anywhere. This website counts page views without cookies, and that's it. We don't sell data.

The twnty app

  • No account, no sign-in.
  • No analytics, no telemetry and no crash reporting.
  • The app makes no network connections of its own. It has no update checker and no code that talks to a server. You can confirm this in the open-source code.
  • Your settings (such as break intervals and eye style) and daily break stats (breaks taken and skipped) are saved as small files in the app's configuration folder on your own computer. They never leave it, and removing the app and that folder removes them.

The operating system may show the app's notifications and, if you turn it on, start it at login. Those are standard OS features that stay on your device.

This website (twnty.app)

  • Hosting. The site is hosted on Vercel, which processes standard server logs, including your IP address, to deliver the site and keep it secure.
  • Analytics. We use Vercel Web Analytics to see aggregate page views and which download button is clicked (macOS or Windows). It sets no cookies and does not track you across other sites.
  • GitHub API. The home page asks GitHub's public API for the latest release number, so your browser contacts api.github.com when the page loads. See GitHub's privacy statement.
  • Theme choice. If you switch between light and dark, that choice is stored in your browser's localStorage on your device. It isn't sent to us.
  • No cookies, no ads, no forms. The site has no accounts, newsletter sign-up or advertising.

Downloads

Installers are served by GitHub Releases, not by this site. When you download one, GitHub handles that request under its own privacy statement.

Selling and sharing data

We don't sell your data and we don't share it for advertising. The only third parties involved are the service providers named above (Vercel and GitHub).

Children

twnty doesn't collect personal information from anyone, including children, and the website doesn't knowingly collect it either.

Changes to this policy

If this policy changes, the date at the top will change with it. The history is public in the GitHub repository.

Contact

Questions or concerns? Please open an issue on GitHub.
